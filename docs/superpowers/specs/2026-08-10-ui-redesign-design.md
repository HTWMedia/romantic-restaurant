# 《浪漫小餐厅》UI 视觉改版设计文档

> 日期：2026-08-10
> 目标：将当前"纯色直角矩形 + 平铺文字"的简陋 UI 升级为**温馨治愈风 · 奶油暖调**的成品手游质感，不改动布局结构和 core 层业务逻辑。

## 1. 范围

覆盖全部 UI 区块：HUD 顶栏、菜单栏、厨房面板、场景内元素（顾客/满意度条/桌子/背景装饰）、升级弹窗。背景增加餐厅氛围装饰。保持现有布局分区与坐标基本不变。

## 2. 视觉系统

### 2.1 配色（替换现有 `COLOR` 表）

| 用途 | 色值 | 说明 |
|---|---|---|
| 背景底色 | #F7E8D7 | 奶油米色 |
| 背景装饰深色 | #E8D3BC | 地面/装饰 |
| 卡片面板 | #FFF7EE | 奶油白 |
| 卡片描边 | #E3CDB4 | 浅木色 |
| 主色（按钮/强调） | #FF8A5C | 暖橙 |
| 辅助色（选中/金币） | #FFC94D | 蜂蜜黄 |
| 薄荷绿（满意度高） | #7ED9A7 | |
| 警示红（满意度低） | #E86A5E | |
| 主文字 | #5A4632 | 深棕 |
| 次要文字 | #9C8568 | 浅棕 |

### 2.2 圆角 / 阴影 / 字体

- 所有面板/按钮用 `roundRect`（圆角半径 8~16px），替换现有直角矩形。
- 卡片下方垫一层半透明 rgba(90,70,50,0.15) 的偏移矩形（向下 4px）模拟柔和投影。
- 标题加大加粗，正文统一 16~18px，行高自动（Label 默认字体）。

## 3. 组件设计

### 3.1 HUD 顶栏（y≈293，920×58 圆角卡片 + 描边 + 投影）

- 金币徽章块：圆形金币图标 + 「金币」标签 + 数字（图标用脚本 PNG 或 emoji 圆底）。
- 在店人数：中间，前置小人 emoji，数字醒目。
- 等级：右侧两个小标签「桌 L1」「厨 L1」，圆角浅色底。
- 升级按钮：暖橙圆角胶囊，hover 变深。

### 3.2 菜单栏（y≈-265，920×110 圆角卡片底）

- 每道菜独立圆角卡片（130×72，圆角 12，奶油白底 + 浅木描边），卡片间 14px 间距居中。
- 卡片内容：菜名（14px 加粗）+ 价格（12px，蜂蜜黄 + 金币图标）。
- 已解锁：白底；选中时描边变暖橙 + 底色微染 + 轻微放大。
- 未解锁：半透明灰卡片，中央 🔒 + 价格；金币够时描边变蜂蜜黄（暗示可买）。

### 3.3 厨房面板（x=360, y=-80，230×170 圆角卡片 + 投影）

- 标题「厨房」带 🍳 emoji。
- 新增圆形进度环（`Graphics.arc`），选菜后转圈，剩余时间显示在圆心。
- 状态三段：空闲（选一道菜吧）/ 制作中（进度圈转 + 剩余秒数）/ 完成（进度圈满 + 按钮闪烁）。
- 按钮改胶囊圆角，制作中置灰禁点，完成后高亮。

### 3.4 场景内元素

- 顾客身体圆角矩形（圆角 20），奶油白底 + 浅木描边；头部圆角方形；气泡圆角（圆角 10）+ 小三角，显示菜名。
- 满意度条圆角条（圆角 3），颜色随满意度 绿→黄→红 **平滑插值**（lerpColor，不再三档跳变）。
- 桌子：圆角矩形 + 深木描边 + 桌面高光 + 两条桌腿。
- 背景装饰：奶油米色背景，y=-40 以下浅木地板线；沿墙加静态窗格/挂画/绿植（Graphics 或 emoji），不遮挡 HUD/菜单/顾客。

### 3.5 升级弹窗（520×320）

- 全屏半透明遮罩 rgba(0,0,0,0.35)；面板奶油白圆角卡片（圆角 20）+ 投影。
- 两个选项横排卡片（各 220×80）：「🪑 加桌位」「⚡ 厨房提速」，显示当前→目标 + 费用。
- 已满级：置灰 + 「已满级」徽章；金币不足：置灰 + 费用变红。
- 右上角 ✕ 关闭（替代文字「关闭」）。

## 4. 动画（Cocos `tween`，全部轻量）

- 弹窗打开缩放 0.9→1 + 淡入，关闭淡出。
- 满意度条颜色每帧插值平滑过渡。
- 厨房完成时按钮呼吸闪烁。
- 金币增加时数字短暂放大跳动。
- 菜单选中态过渡（描边/底色）。

## 5. 架构与文件改动

- `Widgets.ts`：新增 `roundRect`、`panelWithShadow`、`pillButton`、`lerpColor`；替换 `COLOR` 表。
- 各 View（Hud/Menu/Kitchen/Upgrade/Customer/Main）改用新工具函数，布局坐标基本不变。
- core 层零改动。图标第一批用 emoji + Graphics；第二批按需补 PNG。

## 6. 错误处理

- `roundRect`/`arc` 参数非法时按默认值降级（radius 钳制到 [0, min(w,h)/2]）。
- 升级弹窗点击遮罩外部不关闭，仅 ✕ 关闭。

## 8. 实施批次（方案 C）

- **第一批（代码绘图）**：COLOR 表替换、roundRect/panelWithShadow/pillButton/lerpColor、各 View 圆角化、背景装饰、满意度平滑、弹窗遮罩与动画。完成后人工验收。
- **第二批（按需 PNG）**：根据第一批效果，为金币/菜品/桌位/厨房/升级生成脚本 PNG 图标替换 emoji。
